# government-tourism-portal-144871-144881

This repository contains the backend container for the Government Tourism Portal.

- Backend path: backend/
- Start dev: cd backend && npm install && npm run dev
- Default API URL: http://localhost:4000
- Recommended API URL for integration: http://localhost:3001 (set PORT=3001 in backend/.env)

APIs are grouped under the `/api` base path and are ready for integration with the frontend web app.
